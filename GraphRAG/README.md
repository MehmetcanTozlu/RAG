# 🕸️ GraphRAG (Knowledge Graph Retrieval-Augmented Generation)

An advanced, entity-centric RAG implementation using **Neo4j** and **LangGraph** to transcend the limitations of flat vector spaces. 

Standard Vector RAG systems retrieve text chunks based on semantic similarity, which often fails when answering multi-hop reasoning questions or connecting dispersed concepts. **GraphRAG** solves this by constructing a deterministic Knowledge Graph (Nodes/Entities and Edges/Relationships) from the source material. 

This specific implementation is heavily optimized for **Local LLMs (e.g., Qwen2.5-7B Q4 GGUF)**. It tackles inherent small-model challenges—like JSON fragility, hallucination, and catastrophic forgetting—using strict Schema Enforcement, Cross-Lingual Prompting, and True Hybrid Search.

## 🧠 System Architecture & Innovations

The pipeline operates in two distinct phases: **Build** (Knowledge Graph Construction) and **Query** (Hybrid QA).

### Phase 1: Build (Pydantic-Driven Extraction)
Standard LLM extraction often crashes due to malformed JSON outputs (Silent Failures). We enforce strict rules natively:
1. **Document Ingestion & Guardrails:** The PDF is chunked with strict separators. Before entity extraction, the raw text is saved as a `Document` node in Neo4j as a "Security Net".
2. **Structured Decoding (Pydantic):** We bypass fragile Regex parsers by forcing the LLM to output data strictly adhering to a `BaseModel` schema via `JsonOutputParser`.
3. **Cross-Lingual Prompting:** The prompt instructions and schemas are in English (reducing cognitive load), but the target extraction data and labels are forced to be in Turkish.
4. **Graph Injection:** Extracted Entities and Relationships are injected into Neo4j with their exact `source_sentence` attached for verifiable attribution.

### Phase 2: Query (Hybrid Search & Context Pruning)
Retrieval relies on a mathematically robust state machine to prevent "Lost in the Middle" syndrome and Graph Poisoning.
1. **True Hybrid Search (Vector + BM25):** Overcomes the "Vocabulary Gap" (e.g., matching the user's word "cinayet" to the legal term "kasten öldürme") by running simultaneous Dense (Vector) and Sparse (Keyword) searches in Neo4j.
2. **Cypher Multi-Hop Retrieval:** Uses `OPTIONAL MATCH` to safely retrieve graph connections without dropping isolated entity nodes (preventing INNER JOIN traps).
3. **Context Pruning (Amputation):** Automatically hides hallucinatory or "toxic" graph relationships generated by the small local LLM from the final prompt, feeding the generator only clean, verifiable legal texts.
4. **Generate Node:** Produces the final answer using a strict ChatML System Prompt, forcing exact `[1]`, `[2]` citations for every claim.

## 🛠️ Tech Stack
* **Orchestration:** LangGraph (StateGraph), LangChain
* **Graph Database & Vector Store:** Neo4j (Docker Local / AuraDB Cloud)
* **LLM Engine:** Local `Qwen2.5-7B-Instruct` via `llama-cpp-python` (Hardware Accelerated)
* **Schema Enforcement:** Pydantic
* **Embedding Model:** HuggingFace `paraphrase-multilingual-MiniLM-L12-v2`

## 🚀 How to Run

The system is fully modular and configurable via CLI arguments using `argparse`. It autonomously detects if the Neo4j database is empty and triggers the "Build" phase, or skips directly to the "Query" phase if the graph already exists.

**Run with Local Neo4j (Docker):**
```bash
python app.py \
  --db_mode "local" \
  --local_db_user "neo4j" \
  --local_db_password "your_password" \
  --model_path "/path/to/your/Qwen2.5-7B-Instruct.Q4_K_M.gguf" \
  --embedding_model_path "/path/to/embedding/model" \
  --pdf_path "/path/to/document.pdf"
```

**Run with Cloud Neo4j (AuraDB):**

```bash
python app.py \
  --db_mode "cloud" \
  --cloud_db_uri "neo4j+s://your-db-id.databases.neo4j.io" \
  --cloud_db_user "neo4j" \
  --cloud_db_password "your_cloud_password" \
  --model_path "/path/to/your/model.gguf" \
  --embedding_model_path "/path/to/embedding/model"
```

## 🧹 Database Reset Commands (Cypher)
If you need to rebuild the Knowledge Graph from scratch, run these commands in your Neo4j Browser to avoid legacy index crashes:

```cypher
MATCH (n) DETACH DELETE n;
DROP INDEX entity_vector_index IF EXISTS;
DROP INDEX document_vector_index IF EXISTS;
DROP INDEX entity_keyword_index IF EXISTS;
DROP INDEX document_keyword_index IF EXISTS;
```
